# 快消品品牌官网通用模板

一套「响应式品牌官网 + 本地品牌内容编辑器」。同一套代码可服务多个品牌，切换品牌只需替换配置和图片，**无需修改 React/HTML/CSS 代码**。

- 面向访客：简洁、高级、图片主导、手机端优先的品牌官网
- 面向运营：本地可视化编辑器，改文字 / 图片 / 颜色 / 产品 / 链接，实时预览
- 输出：可部署到任意静态托管的纯静态网站

第一版不含账号、数据库、云端 CMS、购物车、支付和复杂动画。购买按钮跳转淘宝等外部平台。

---

## 环境要求

- Node.js ≥ 18.18（推荐 20.x）
- npm ≥ 9

## 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器（官网 + 编辑器）
npm run dev
```

启动后访问：

| 地址 | 用途 |
|---|---|
| http://localhost:3000 | 品牌官网预览（当前激活品牌） |
| http://localhost:3000/editor | 本地品牌内容编辑器 |

打开编辑器后，默认载入示例品牌 **Marlow（Demo）**，所有内容和图片均为占位资料。

## 如何建立一个新品牌

### 方式一：在编辑器中新建（推荐）

1. 打开 `http://localhost:3000/editor`
2. 点击顶部「品牌 ▾ → 新建品牌」，输入品牌名称
3. 在左侧依次编辑：
   - **基本信息**：品牌名、Logo、标语、简介
   - **主题风格**：选择预设或自定义颜色、字体、圆角
   - **导航栏**：增删导航锚点
   - **首屏 / 简介 / 产品 / 卖点 / 场景 / 故事 / FAQ / 联系**：各模块内容
   - **链接与联系**：购买链接（淘宝等）、社媒、邮箱
   - **SEO 与分享**：标题、描述、分享图、favicon
4. 图片字段点击上传框即可上传，文件自动保存到 `brands/{品牌slug}/assets/`
5. 右侧切换「桌面 / 平板 / 手机」检查效果
6. 点击「保存」（或按 `Ctrl/Cmd + S`）

### 方式二：复制现有品牌

在编辑器中「品牌 ▾ → 复制品牌」，基于已有品牌快速派生，再逐项修改。

### 方式三：从 JSON 导入

在「导入 / 导出」中点击「导入 JSON」，选择之前导出的 `.brand.config.json` 文件，会创建为新品牌（自动迁移旧版本配置）。

## 品牌数据存在哪里

```
brands/
├─ _template/              # 空白模板
│  └─ brand.config.json
└─ demo-brand/             # 示例品牌
   ├─ brand.config.json    # 品牌配置（所有内容都在这里）
   └─ assets/              # 该品牌的图片资源
```

- 每个品牌一个目录，配置文件为 `brand.config.json`
- 图片路径相对于品牌目录，例如 `assets/hero.jpg`
- 当前激活品牌记录在 `brands/.active-brand`
- **备份建议**：定期在编辑器中「导出 JSON」，或直接备份整个 `brands/` 目录

## 导出静态网站

### 在编辑器中导出

进入「导入 / 导出 → 静态网站导出」，点击「导出静态网站」。导出前会自动保存并检查必填项、断图、重复 slug。

### 命令行导出

```bash
# 导出当前激活品牌
npm run export

# 导出指定品牌
npm run export -- --brand=demo-brand
```

产物在 `out/` 目录，包含 HTML/CSS/JS、品牌配置和图片资源，以及自动生成的 `robots.txt` 和 `sitemap.xml`。

### 本地预览导出产物

```bash
npx serve out
# 或
python -m http.server -d out
```

### 部署

将 `out/` 目录上传到任意静态托管服务即可：

- Vercel / Netlify / Cloudflare Pages
- 阿里云 OSS / 腾讯云 COS 静态网站
- GitHub Pages
- Nginx

每个品牌单独导出、单独部署，可绑定不同域名。

## 主题定制

内置三套主题预设（编辑器「主题风格」中一键切换）：

| 预设 | 气质 | 适合 |
|---|---|---|
| 自然清新 | 深绿 + 暖米底 | 天然、食品、个护 |
| 柔和精致 | 陶土 + 奶油底 | 美妆、香氛、生活方式 |
| 黑白极简 | 纯黑 + 冷白 | 科技、潮流、极简 |

所有颜色、字体（系统衬线 / 无衬线 / 圆体）、圆角、按钮风格、内容宽度、模块间距均可在编辑器中微调。主题通过 CSS 变量注入，组件中没有硬编码颜色。

## 可用模块

| 模块 | 必需 | 说明 |
|---|---|---|
| 顶部导航 | 是 | Logo、锚点导航、购买按钮（移动端折叠） |
| Hero 首屏 | 是 | 标题、副标题、CTA、主视觉；四种布局（右图左文 / 左图右文 / 居中堆叠 / 全屏横图），居中可切换图文上下顺序，图片可多图轮播 |
| 品牌简介 | 是 | 定位、简短故事、配图，可切换图文左右顺序，支持多图轮播 |
| 核心产品 | 是 | 产品卡片（contain 不裁切包装）、卖点、规格、购买链接；每个产品可上传多张图并轮播 |
| 核心卖点 | 是 | 3–6 个短卖点，可配 emoji |
| 场景种草 | 否 | 生活方式图片 + 短文案（cover 裁切），每个场景支持多图轮播 |
| 品牌故事 | 否 | 完整故事、价值观、配图，可切换图文左右顺序，支持多图轮播 |
| FAQ | 否 | 折叠面板，键盘可操作 |
| 联系/CTA | 否 | 行动号召区块 |
| 页脚 | 是 | 社媒、邮箱、法律链接、版权 |

每个模块可独立显示/隐藏、调整排序。可选模块没有内容时自动隐藏，不留空白。

### 图片、轮播与布局

- **多图轮播**：首屏、品牌简介、场景、品牌故事、每个产品都可上传多张图片。上传 2 张及以上后，编辑器会出现「多图轮播」开关；开启后官网以轮播展示（指示点、左右箭头、手机端可左右滑动），可再开「自动播放」并设置间隔。关闭轮播时只显示第一张。
- **首屏四种布局**：右图左文、左图右文、居中堆叠、全屏横图。全屏横图会把横向大图作为占满首屏的背景，文字以白色叠加其上（自带暗色遮罩保证可读），顶部导航在页面顶端透明、滚动后恢复实底，建议使用 1920px 以上的横向高清图。
- **图文顺序**：首屏「居中堆叠」可切换图片在文字上方或下方；品牌简介、品牌故事可切换图片在文字左侧或右侧。
- 每张图片都可单独设置替代文本（无障碍 / SEO）与裁切焦点（居中、顶部、底部等）。
- **替换图片**：在编辑器图库中点击任意缩略图（或悬浮时显示的铅笔图标）即可选择新图片替换这一张；「+ 添加图片」用于追加新图。
- **标题换行**：所有模块的主标题、副标题、产品副标题、FAQ 问题等在编辑器中均支持回车换行，官网按换行显示（同时保留窗口变窄时的自动折行）。
- **页面模块排序**：编辑器左侧「页面模块排序」可用上下箭头调整整块模块的顺序（如把「场景种草」移到「核心卖点」上方），并可在此开关各模块显示/隐藏，预览实时更新。
- **页脚标题自定义**：「链接与联系」中可修改页脚「关注我们」「联系」两栏的标题文字。

## 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动本地开发服务器（官网 + 编辑器） |
| `npm run build` | 构建 Next.js 应用（不导出品牌） |
| `npm run export -- --brand=slug` | 导出指定品牌的静态网站到 `out/` |
| `npm run typecheck` | TypeScript 类型检查 |
| `npm test` | 运行测试（Vitest） |
| `npm run test:watch` | 测试监听模式 |

## 技术栈

- Next.js 14（App Router）+ TypeScript
- Tailwind CSS + CSS Custom Properties（主题变量）
- Zod（配置校验与迁移）
- Zustand（编辑器状态）
- Vitest + Testing Library（测试）
- 自定义 Node 服务器（本地文件系统 API）

## 已知限制（V1）

- 编辑器建议在桌面浏览器使用（平板/手机端编辑器布局有限，官网本身完全响应式）
- 图片上传为原图保存，未做自动压缩和多尺寸生成
- 多语言字段已预留但编辑器未完整支持
- 不包含购物车、支付、账号、在线 CMS
- 产品购买仅支持跳转外部链接
